Big Picture Architecture (How Code is Organized)

We use Feature-Sliced Domain Architecture. Instead of putting hundreds of files into one giant folder, we divide code by business features.

System Layer Block Diagram
USER BROWSER Chrome / Safari / Mobile
⇄
NEXT.JS 16 APP ROUTER App Router + Turbopack
⇄
FEATURE SLICES Home, Listing, Tour, Booking
⇄
MOCK DATA & ASSETS 43 Photos, Hosts, Stays
Folder What Lives Inside? Why It Is Kept Separate

Engineering Problems, Why They Happened & How We Solved Them

Every technical hurdle we met, the root cause, the chosen technology, and before/after comparisons.

Problem 1: Header Logo & Controls Misalignment Across Pages Visual Bug

Why We Faced It: The Home page header was set to max-w-[1760px] with px-20 padding and negative margin -ml-8 on the logo, while the Room detail page was set to max-w-7xl (1280px). When switching pages, the logo jumped sideways by over 130px.

❌ BEFORE (Misaligned Containers)

Home: max-w-[1760px] -ml-8 pt-2 (Logo is far left)

Room: max-w-7xl -ml-2 pt-0 (Logo is pushed inward by 130px)

[Home Logo: 80px from left] ----------- [Room Logo: 210px from left]
✅ AFTER (Unified Layout in Tailwind)

Both pages: max-w-[1760px] px-8 md:px-12 min-[1138px]:px-20

Added balanced inner row padding px-2 sm:px-4 and zero negative margins.

[Both Logos: Exact Same Coordinate Across Both Pages!]

Technology Solution: Tailwind CSS responsive container tokens + unified 80px (h-20) header height.

Problem 2: Corrupted / Broken Image in Noida Carousel (HTTP 404) CDN Failure

Why We Faced It: In the "Check out homes in Noida" section, card 4 ("Room in Sector 75") had an Unsplash URL that was deleted on the external server, returning an HTTP 404 Not Found and showing an ugly broken image box.

Resilient Image Fallback Diagram
1. Broken CDN URL Unsplash returns 404
→
2. React onError Triggers Synthetic event caught
→
3. Automatic Fallback Swap Sets verified high-res photo
→
4. Perfect UI Rendered Zero broken icons! 
// The Resilient Solution in React:
<img
  src={item.images[0]}
  alt={item.title}
  onError={(e) => {
    const target = e.currentTarget;
    if (!target.src.includes('photo-1590490360182-c33d57733427')) {
      target.src = 'https://images.unsplash.com/photo-1590490360182-c33d57733427?auto=format&fit=crop&w=800&q=80';
    }
  }}
/>
Problem 3: Bento Grid Photo Mismatch & Wrong Lightbox Photo State Desync

Why We Faced It: In the Room page Bento Grid, the user clicked on the Jacuzzi photo (or Bedroom / Exterior), but the Lightbox opened showing photo 1 (Living room 1) or Kitchen! This happened because ALL_43_PHOTOS had Kitchen at position 4 and Jacuzzi at position 3, while the click handler used hardcoded idx + 1 numbers.

❌ BEFORE (Desynchronized Array)

Index 2 = Bedroom

Index 3 = Jacuzzi

Index 4 = Kitchen (Exterior was missing!)

Clicking Exterior called onOpenLightbox(4) which opened Kitchen!

✅ AFTER (Exact 1:1 Synchronized Order)

Index 0 = Living room 1

Index 1 = Living room couch

Index 2 = Jacuzzi

Index 3 = Bedroom

Index 4 = Exterior Amor de Goa

Dynamic ID Resolution
User Clicks Jacuzzi Tile id = 'img-03'
→
photos.findIndex(p => p.id === photo.id) Dynamically finds exact index (2)
→
Lightbox Opens at Index 2 Displays Jacuzzi in Lightbox!
Problem 4: Browser Back Button Exited Website Instead of Closing Modal Routing Bug

Why We Faced It: In typical React apps, modals are just isOpen = true in state. If a user opened the Photo Tour and pressed the browser's Back button, the browser had no history entry for the modal, so it closed the entire website!

How We Solved It: We wired the modal to the HTML5 History API using window.history.pushState and popstate listeners in useViewState.ts:

History Stack Block Diagram
1. Base Room Page /rooms/candolim
Push State →
2. Photo Tour Modal /rooms/candolim?modal=PHOTO_TOUR_SCROLLABLE
User Clicks Browser Back ←
3. Popstate Event Closes Modal User stays safely on /rooms/candolim!
Problem 5: Floating Sticky Category Headings in 43-Photo Tour UX Innovation

Why We Faced It: In a huge 43-photo tour covering 9 rooms, users scrolling down would easily get lost and forget which room's photos they were inspecting.

How We Solved It: We designed a two-column responsive layout where the left room title column uses CSS position: sticky; top: 96px;. As you scroll through 5 pictures of "Full kitchen", the kitchen heading stays pinned on your left, and smoothly unsticks when the next room arrives!

Sticky Headings Diagram
Left Column (4 cols) md:sticky md:top-24
Pins on screen while scrolling
Right Column (8 cols) Photo 1, Photo 2, Photo 3, Photo 4
Scrolls naturally with user thumb / mouse
Problem 6: Header Morphing Jitter & Scroll Flickering Animation Bug

Why We Faced It: Using a simple check like if (scrollY > 20) setIsScrolled(true) caused the header to rapidly flash and bounce between 180px and 80px whenever the user scrolled slowly around 20px.

How We Solved It: We implemented a Deadband Hysteresis Algorithm:

Deadband Hysteresis Logic
Scroll Down > 30px Header collapses to 80px
⇄
Deadband Zone (6px – 29px) No state change allowed! Zero jitter!
⇄
Scroll Up <= 5px Header expands back to 180px
Problem 7: Mobile SubNavbar & Reserve CTA Overlap Mobile Layout Collision

Why We Faced It: On smartphone viewports, the sticky SubNavbar tabs collided with the floating bottom Reserve button, causing buttons to overlap and become untappable.

How We Solved It: Used clean responsive breakpoints (hidden md:flex on the top SubNavbar, and md:hidden on the bottom mobile reserve sheet) with separate z-index stacking layers.

Problem 8: "Meet Your Host" Card Distortion & Low-Res Co-Host Avatars Visual Distortion

Why We Faced It: The host card stretched across the entire screen width on desktop screens, looking bloated, and co-host portraits were low-resolution generic placeholders.

How We Solved It: Constrained the host card width to max-w-[332px] matching the real Airbnb card, added a high-resolution Unsplash host portrait with pink verified Superhost badge, and mapped 6 local co-host avatars in a 2x3 grid.
