Big Picture Architecture (How Code is Organized)

We use Feature-Sliced Domain Architecture. Code is cleanly separated into modular features instead of being dumped into one large folder.

System Layer Block Diagram
USER BROWSER Chrome / Safari / Mobile
⇄
NEXT.JS 16 APP ROUTER Server & Client Components
⇄
FEATURE SLICES Home, Listing, Tour, Booking
⇄
MOCK DATA & ASSETS 43 Photos, Hosts, Stays
Feature Directory What Lives Inside? Why It Is Kept Separate
src/features/home/ HomeHeader, ListingCarousel, DestinationCarousel, InspirationSection Keeps the discovery feed and category tabs isolated from room details.
src/features/listing/ PhotoBentoGrid, PropertyOverview, ListingHeader, SubNavbar Encapsulates the 5-photo bento grid and room specifications.

Engineering Problems, Why They Happened & How We Solved Them

Every technical hurdle encountered during development, the root cause, and the clean solution with block diagrams.

Problem 1: Header Logo & Controls Misalignment Across Pages Visual Bug

Why We Faced It: The Home page header was set to max-w-[1760px] with px-20 and negative margin -ml-8 on the logo, whereas the Room detail page was set to max-w-7xl (1280px). When navigating between pages, the logo jumped sideways by more than 130px.

❌ BEFORE (Misaligned Containers)

Home: max-w-[1760px] -ml-8 pt-2 (Logo sits far left)

Room: max-w-7xl -ml-2 pt-0 (Logo sits 130px further inward)

[Home Logo: 80px from edge] ≠ [Room Logo: 210px from edge]
✅ AFTER (Unified Responsive Layout)

Both pages: max-w-[1760px] px-8 md:px-12 min-[1138px]:px-20

Removed negative margins; added px-2 sm:px-4 inner breathing room.

[Both Logos: Exact Same Coordinate Across Both Pages!]

Technology Solution: Tailwind CSS responsive container tokens + unified 80px (h-20) header height.

Problem 2: Corrupted / Broken Image in Noida Carousel (HTTP 404) CDN Failure

Why We Faced It: In the "Check out homes in Noida" section, card 4 ("Room in Sector 75") pointed to an Unsplash photo that was deleted on the CDN, returning an HTTP 404 Not Found and rendering an exposed broken image icon.

Resilient Image Fallback Flow
1. Dead CDN Link Unsplash returns 404
→
2. React onError Catches Synthetic event intercepted
→
3. Automatic Fallback Swap Sets verified high-res photo
→
4. Clean UI Restored Zero broken icons! 
// Resilient Image Fallback in React:
<img
  src={item.images[0]}
  alt={item.title}
  onError={(e) => {
    const target = e.currentTarget;
    if (!target.src.includes('photo-1590490360182-c33d57733427')) {
      target.src = 'https://images.unsplash.com/photo-1590490360182-c33d57733427?auto=format&fit=crop&w=800&q=80';
    }
  }}
/>
Problem 3: Bento Grid Photo Mismatch & Wrong Lightbox Photo State Desync

Why We Faced It: In the Room page Bento Grid, clicking on the Jacuzzi photo (or Bedroom / Exterior) opened the Lightbox showing Photo 1 (Living room 1) or Kitchen. This occurred because ALL_43_PHOTOS had Kitchen at position 4 and Jacuzzi at position 3, while the click handler used hardcoded idx + 1 numbers.

❌ BEFORE (Desynchronized Array)

Index 2 = Bedroom

Index 3 = Jacuzzi

Index 4 = Kitchen (Exterior was missing!)

Clicking Exterior called onOpenLightbox(4) which opened Kitchen!

✅ AFTER (Exact 1:1 Synchronized Order)

Index 0 = Living room 1

Index 1 = Living room couch

Index 2 = Jacuzzi

Index 3 = Bedroom

Index 4 = Exterior Amor de Goa

Dynamic ID Resolution
User Taps Jacuzzi Tile id = 'img-03'
→
photos.findIndex(p => p.id === photo.id) Dynamically finds exact index (2)
→
Lightbox Opens at Index 2 Displays Jacuzzi in Lightbox!
Problem 4: Browser Back Button Exited Website Instead of Closing Modal Routing Bug

Why We Faced It: In traditional React apps, modal state lives in component memory (isOpen = true). When a user opened the Photo Tour and pressed the browser's Back button, the browser had no history entry for the modal, causing the user to navigate completely away from the page.

How We Solved It: We integrated the modal with the HTML5 History API using window.history.pushState and popstate listeners in useViewState.ts:

History Stack Block Diagram
1. Base Room Page /rooms/candolim
Push State →
2. Photo Tour Modal ?modal=PHOTO_TOUR_SCROLLABLE
Press Browser Back ←
3. Popstate Closes Modal User stays safely on room page!
Problem 5: Floating Sticky Category Headings in 43-Photo Tour UX Innovation

Why We Faced It: In a large 43-photo gallery containing 9 room categories, users scrolling down lost context regarding which room they were examining.

How We Solved It: We structured a two-column responsive layout where the left column uses CSS position: sticky; top: 96px;. As the user scrolls through the photos of "Full kitchen", the kitchen heading stays pinned on the left and smoothly unsticks when the next room arrives.

Sticky Headings Diagram
Left Column (4 cols) md:sticky md:top-24
Pins on screen while scrolling
Right Column (8 cols) Photo 1, Photo 2, Photo 3, Photo 4
Scrolls naturally with thumb / mouse
Problem 6: Header Morphing Jitter & Scroll Flickering Animation Bug

Why We Faced It: A single scroll threshold (e.g. scrollY > 20) caused the header to rapidly flash and bounce between 180px and 80px whenever the user scrolled slowly near 20px.

How We Solved It: We implemented a Deadband Hysteresis Algorithm:

Deadband Hysteresis Logic
Scroll Down > 30px Header collapses to 80px
⇄
Deadband Zone (6px – 29px) No state change allowed! Zero jitter!
⇄
Scroll Up <= 5px Header expands back to 180px
Problem 7: Mobile SubNavbar & Reserve CTA Overlap Mobile Collision

Why We Faced It: On phone screens, the sticky SubNavbar tabs collided with the bottom fixed reserve button, causing buttons to overlap and become untappable.

How We Solved It: Used clean responsive breakpoints (hidden md:flex on the top SubNavbar, and md:hidden on the bottom mobile reserve sheet) with separate z-index stacking layers.

Problem 8: "Meet Your Host" Card Distortion & Low-Res Co-Host Avatars Visual Distortion

Why We Faced It: The host card stretched across the entire screen width on desktop screens, looking bloated, and co-host portraits were low-resolution generic placeholders.

How We Solved It: Constrained the host card width to max-w-[332px] matching the real Airbnb card, added a high-resolution Unsplash host portrait with pink verified Superhost badge, and mapped 6 local co-host avatars in a 2x3 grid.
